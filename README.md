# Rootline

**The landscape business operating system** (working name). This repository holds the product design proposal for an all-in-one platform for small and medium landscape companies.

Rootline runs a landscape company in one system, from first photo to closed books:

- to-scale designs and honest AI mockups of the client's own yard, using plants rated for the client's region;
- priced proposals with e-signature and deposits;
- crew schedules and routes, run in an offline-first, Spanish-first crew app;
- invoicing and payments through each Company's own Stripe account, with zero markup by default;
- a built-in double-entry ledger that closes the books.

An operator-curated, region-aware Plant Knowledge Base underpins design, estimating and client care.

Rootline launches in one region, the **Great Lakes** (Ohio, Michigan, Chicagoland and Northwest Indiana, Southeast Wisconsin), and extends it across the border into Ontario's Golden Horseshoe at V1. Because Great Lakes crews plow in winter, the MVP includes **Snow Lite**: storm visit logs with GPS-stamped photos, per-push invoices and a per-site proof-of-service PDF, in every plan.
